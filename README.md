# Microsoft Power Platform - Plataforma Educativa y Manual de Aprendizaje

Plataforma educativa moderna, interactiva y responsive para el aprendizaje integral de **Microsoft Power Platform**:
- **Power Apps** (Canvas Apps, fórmulas Power Fx, validaciones)
- **Power Automate** (Flujos de nube, aprobaciones, control de bucles)
- **Microsoft Lists** (Modelado estructurado de datos, tipos de columnas, vistas)
- **SharePoint** (Gestión documental, sitios, herencia de permisos y seguridad)

## 🚀 Características
- **100% Responsive**: Adaptado a móviles (320px+), tablets y monitores de escritorio con arquitectura mobile-first.
- **15 Capítulos Completos**: Cobertura fiel del manual oficial y ampliaciones pedagógicas.
- **Herramientas de Estudio Activo**:
  - 🎴 **Flashcards interactivas**: Repaso con giro 3D y clasificación por nivel de aprendizaje.
  - 📝 **Cuestionario de Evaluación**: Validación en tiempo real y explicaciones detalladas.
  - 🔍 **Buscador Global Inteligente**: Búsqueda instantánea de fórmulas, conceptos y lecciones (`Ctrl+K`).
  - ⏱️ **Cronómetro de Estudio y Seguimiento de Progreso**: Persistencia local con `localStorage`.
  - 🎯 **Plan Personal de Acción**: Checklist de autoevaluación práctica.

## 🛠️ Tecnologías
- **HTML5** semántico
- **CSS3** moderno (Variables CSS, Flexbox, Grid, Clamp, Dark Mode)
- **JavaScript** modular y nativo
